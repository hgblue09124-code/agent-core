# AI Engineering Contract for Cửu Giới (Nine Realms)

## Overview
This document serves as the primary AI Engineering Contract for the Cửu Giới project.
It defines all architectural boundaries, operational constraints, and verification criteria required for automated or agent-assisted development.

## Core Principles
1. Deterministic Execution: All procedures must be reproducible and testable.
2. Independent Verification: Code changes must be validated by tests and evidence ledgers.
3. Strict Architectural Isolation: Boundaries between core kernel, experience, and knowledge layers must be preserved.

## System Structure
- Core Kernel: Orchestrates execution, manages state transitions, and enforces invariants.
- Knowledge System: Stores verified primitives and evidence chains.
- Experience Engine: Captures execution runs and extracts reusable insights.
