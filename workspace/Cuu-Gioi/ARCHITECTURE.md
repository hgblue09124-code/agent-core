# ARCHITECTURE.md — Cửu Giới (Nine Realms)

## Overview
Cửu Giới (Nine Realms) is a multi-domain modular framework designed for high-reliability systems.

## Key Architectural Layers
1. Realm 1: Core Foundation & Runtime Control
2. Realm 2: Knowledge Graph & Primitive Registry
3. Realm 3: Experience & Analyzer Systems
4. Realm 4: Task Decomposition & Execution Engine
5. Realm 5: Verification & Independent Evaluation Engine
6. Realm 6: Events & Redaction Layer
7. Realm 7: Policy & Safety Invariant Engine
8. Realm 8: Console & Monitoring Adapter
9. Realm 9: Strategy & High-Level Planner Interfaces

## Architectural Rules
- Components must maintain clean interfaces without circular dependencies.
- All persistent operations must use atomic file transactions.
